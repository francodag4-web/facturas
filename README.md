# Facturas

App de facturación para autónomos que funciona entera en el navegador: numeración correlativa por año, datos del emisor y del cliente, partidas editables, IRPF/IVA calculados automáticamente, plantillas de diseño, historial y PDF.

**Privacidad:** el repositorio solo contiene la app. Las facturas y los clientes no se suben nunca. Se guardan en un archivo `.json` del ordenador de quien la usa (en Chrome o Edge) y en el propio navegador.

Uso: abrir la página → pestaña *Historial* → **Crear archivo nuevo** (mejor dentro de Google Drive u OneDrive) → rellenar *Mis datos* → facturar → **Guardar y PDF**.
